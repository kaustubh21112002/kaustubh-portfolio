## Confidence Level Taxonomy

Throughout these documents, statements are classified using this standardized taxonomy:
- **[VERIFIED]**: Confirmed directly via active source code, scripts, or configuration.
- **[PARTIALLY VERIFIED]**: Implementation exists, but some aspects or edge cases remain in review.
- **[UNVERIFIED]**: Reference or proposal not yet grounded in repository code.
